What an API and MCP are
An API is the door one piece of software opens for another. MCP is a standard way for an agent to plug into those doors without custom code for each one.
Rule of thumb: any key that would cost you money if leaked never goes into a chat window.
Ask about this program
MCP vs API, and where do my keys go?
MCP is a layer around an API that lets an agent connect quickly; underneath it is still the API 1. Low-risk keys can live in a .env file; anything costly goes in a password manager and the agent asks each time 2.

Everything a paid learning community needs

Stop stitching together a course tool, a forum, a chat app, a calendar and a checkout. DigiSkill keeps them in one place, behind one member login.

Community spaces

Spaces grouped the way members already know: a home feed, discussions, Q&A with accepted answers, polls, files and embeds. Mentions and notifications set per space.

Cohort classes

Write a program once and run it as many cohorts as you like. Each cohort has its own schedule, deadlines, instructors, seats and progress, scheduled or self-paced.

Course builder

Lessons built from blocks: video, text, images, PDFs, downloads and assignments. Unlock lessons on a schedule and keep unfinished ones hidden. Paid files never leak through public links.

Assignments that teach

Members submit their work, then see how classmates solved the same task and leave comments. Instructors and teaching assistants follow every class from the web.

Live sessions and replays

Stream from OBS straight into the class. Every session is recorded and attached to the cohort, so members who missed it watch the replay in the same place.

Member billing

Sell a seat in a cohort or access to a space, with Stripe. A new member pays, gets an email, signs in with a one-time code and lands in the right class.

How a cohort runs on DigiSkill

The program is the content. The cohort is the people, the dates and the conversation. Keeping them apart is what lets you run the same course again without starting over.

01

Build the program

Modules, lessons, videos, files and assignments, written once in the course builder.

02

Open a cohort

Set dates, seats, price and instructors. The cohort gets its own course, announcements, Q&A, chat and calendar.

03

Learn together

Lessons unlock on schedule, members join live sessions, submit work and help each other in the class space.

04

Run it again

Open the next cohort from the same program. Progress and submissions stay with each cohort; past cohorts keep their replays.

Questions

Who is DigiSkill for?+

Organisations that teach at scale: academies, training companies, corporate learning teams and large paid communities that want the lessons, the conversation and the payments in one place, under their own brand.

How is it different from a course tool or a forum?+

Most tools lean towards either courses or community. DigiSkill puts the cohort at the centre: its lessons, schedule, chat, Q&A and replays live together, and the next cohort reuses the program without mixing anyone's progress.

Can I use my own domain?+

Yes. Every community starts on its own digiskill.ai address and can move to a domain you own. The original address keeps working and redirects.

Do members need to install anything?+

No. DigiSkill runs in the browser and members sign in with a one-time code sent to their email, no password to remember. Installing it on a phone home screen is on the roadmap.

Is there a self-serve or free plan?+

No. DigiSkill is available for Enterprise only. Write to business@digiskill.ai and we will set up a plan for your organisation.
